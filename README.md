# Ladronka Gardens — demo web

Statický web (HTML, CSS, JS), žádný build není potřeba.
Vizuální koncept a identita: Renata Sofina, 2026.

## Zveřejnění na GitHub Pages
1. Na GitHubu vytvořte nový veřejný repozitář (např. `ladronka-gardens`).
2. *Add file → Upload files* → přetáhněte **obsah** této složky (index.html, raj.css, raj.js, img/, fonts/, vendor/ …), ne složku samotnou → *Commit changes*.
3. *Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main, / (root) → Save*.
4. Po 1–2 minutách bude web na `https://<uživatel>.github.io/<repozitář>/`.

## Lokální náhled
V této složce spusťte `python3 -m http.server` a otevřete http://localhost:8000.

Vizualizace jsou ilustrativní. Formulář je ukázkový a nic neodesílá.
